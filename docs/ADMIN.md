# Admin & Office Team Features

## Admin Dashboard

- **Event Creation Wizard:** Type, date/time, location (with map pin), mode (online/offline), available slots, required skills, registration deadline, description. One tap to create and auto-notify all volunteers.
- **Approval Queue:** After allocation runs, admin sees the ranked list with priority scores. Can approve the algorithm's recommendation or manually override (drag-and-drop reorder).
- **Verification Review:** Pending photo proofs, disputed check-ins, self-reported hours awaiting confirmation. Approve/reject with one tap.
- **Do Not Contact List:** Flag volunteers who shouldn't be contacted. They're excluded from notifications and allocations.

## Reports

| Report | What It Shows | Who Uses It |
|---|---|---|
| Volunteer Activity Summary | Per-volunteer: events attended, hours contributed, points earned, verification rate, streak status | Admin, individual volunteer (own data) |
| Consistency Tracker | Who is consistently active, who is declining, who has gone silent. Colour-coded: green (active), yellow (declining), red (dormant 60+ days) | Admin |
| Student vs. Alumni Breakdown | Volunteering split by role. Identify if alumni are drifting or students aren't engaging. | Admin, leadership |
| Availability Calendar | Which panel/mock-interview volunteers are available when. Heat map by day-of-week and time. | Admin (for planning) |
| Employer Organisation Summary | "TCS volunteers: 8 people, 120 hours this quarter." Exportable PDF to share with CSR teams. | Admin, employer orgs |
| Leaderboard Report | Top contributors by points, hours, events — filterable by time period and activity type. | Admin, all volunteers (public version) |
